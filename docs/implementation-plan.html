Scry Phase 1 MVP

Implementation plan — Terminal SQL client — LuaJIT + termbox2 + luasql

01Goal & Scope

🎯 What will ship

A single statically-linked binary that connects to PostgreSQL 12+, MySQL 8+/MariaDB 10.5+, and SQLite 3. Users edit SQL, execute with Ctrl+r, view paginated results, filter/sort, export CSV/JSON, enforce read-only, and use SSH tunnels. Tests cover parser, config, read-only, exports, history, and a fuzz target.

In scope

  • Postgres adapter (libpq async)
  • MySQL/MariaDB adapter (MariaDB Connector/C)
  • SQLite adapter done
  • Result grid with pagination, sort, filter
  • Sidebar table/column browser
  • Read-only enforcement (CTE-aware)
  • CSV + JSON export
  • History persistence (history.jsonl)
  • SSH tunneling
  • Fuzz target for SQL splitter
  • CI on Linux, macOS, Windows

Out of scope

  • Phase 2 NoSQL (MongoDB, Redis)
  • Result-set tabs
  • Autocomplete
  • Native DB cancellation (PQcancel etc.)
  • Auto-transaction wrapping
  • Additional themes beyond dark/light
  • Plugins / extension system
  • Database-level pagination rewrites
  • Clipboard export

07Risks & Decisions
RiskLikelihoodImpactMitigation
luasql PR #201 bugsMediumHighDriver capability tests. Pin exact SHA.
MySQL blocks event loopCertainMediumDocumented. UI shows "Transferring…". Phase 2 fix.
SQLite Ctrl+C latencyLowLowDocument in README. Phase 2: sqlite3_interrupt.
Nested block commentsLowLowDocumented limitation. Fuzz target.
MariaDB Connector/C missingMediumHighDocument prerequisite. CI installs.
Tests fail (no TTY)HighMediumMock terminal for unit tests.
Close-and-reconnect slowMediumLowPhase 1 documented. Phase 2 native option.

Halt-on-first failure

Stops at first failed Statement. Chosen over run-all because mid-buffer failure in BEGIN/COMMIT leaves ambiguous transaction state.

Close-and-reconnect cancellation

Ctrl+c closes connection, prompts reconnect. Avoids FFI coupling to version-dependent driver handles.

next_row() only

No materialize-everything method. Grid caps at max_result_rows, export streams to file. Both consume off next_row().

Executable Lua config

No YAML/TOML. os.getenv() and functions directly. Connections replaced wholesale by name to prevent Frankenstein configs.

09Acceptance Checklist

Build & Run

  • make all works on Linux, macOS, Windows
  • scry --version and --help
  • Binary ≤ 3 MB
  • Cold startup P50 < 50ms
  • Idle memory < 50 MB

Connectivity

  • PostgreSQL 12+
  • MySQL 8+ / MariaDB 10.5+
  • SQLite 3
  • Health check after connect
  • 10s timeout

Execution

  • Ctrl+r executes buffer/selection
  • Multi-statement halt-on-first
  • Paginated grid results
  • Sort, filter, pagination
  • Ctrl+c cancels

Read-only

  • --read-only flag
  • SELECT/EXPLAIN/SHOW allowed
  • Write keywords blocked
  • CTE-aware classification

Export & History

  • Ctrl+e CSV, Ctrl+Shift+e JSON
  • Export guarded to single SELECT
  • History persisted
  • Ctrl+p/Ctrl+n navigate

Tests

  • All unit tests pass
  • Integration tests (PG, MySQL, SQLite)
  • Fuzz: 100k iterations, no crash
  • Driver capability tests

Final gate

make all && make test && ./scry --version && ./scry --help — all green.
